# 🍵 Teaboom — Карточка товара

Адаптивная карточка товара для интернет-магазина чая Teaboom.  
Цель — показать интерактивный компонент с выбором фасовки, динамической ценой и адаптивной вёрсткой под разные устройства.
Сделано в рамках тестового задания.

---

## 🔗 Демо  
👉 [Открыть Teaboom Card](https://megacerera.github.io/teaboom-card-test/)

---

## ✨ Функционал / особенности  
- Адаптивная вёрстка: макет под разные разрешения экрана  
- Выбор фасовки (100 г, 500 г, 1000 г, 5000 г) с пересчётом цены  
- Динамическое обновление артикула, текущей и старой цены  
- Хлебные крошки с адаптивным поведением  
- Аккуратные hover-состояния и доступность (`aria-live`, `visually-hidden`)

---

## 🛠 Технологии  
- HTML5 (семантическая вёрстка)  
- SCSS
